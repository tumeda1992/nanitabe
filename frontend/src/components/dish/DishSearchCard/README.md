# DishSearchCard

料理1件の表示カード。3バリアント構成。

## バリアント構成

| ファイル | 役割 | 使用場面 |
|---------|------|---------|
| `index.tsx` | ベース表示のみ。`trailing` スロットで拡張可能 | 他バリアントの内部で使用 |
| `Library.tsx` | アクションメニュー（編集/削除）付き。チェックボックス任意 | 料理検索ページ・食事登録 |
| `Picker.tsx` | 選択チェックマーク付き | 食事割当（ChooseDish） |

## 不変条件

- MUST: `Library` にアクションメニューが不要な場合は `onEdit`/`onDelete` を渡さないこと（渡さなければメニューは表示されない）
- MUST: 新しい表示バリアントが必要な場合は `index.tsx` の `trailing` スロットを使って `Library`/`Picker` と同じ構造で追加する
